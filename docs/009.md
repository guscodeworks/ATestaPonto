# Referência técnica

Este documento reúne tabelas de consulta rápida. Explicações conceituais ficam nos documentos anteriores.

## Projetos e scripts

### `ponto-escolar`

| Script | Função |
| --- | --- |
| `npm start` | Inicia o sistema principal. |
| `npm run start:ponto` | Alias para iniciar o sistema principal. |
| `npm run start:govbr` | Inicia o simulador a partir da pasta `gov.br-fake`. |
| `npm run dev` | Inicia sistema principal e simulador com `concurrently`. |
| `npm run db:init` | Inicializa o banco a partir do schema localizado pelo script. |
| `npm run db:run` | Executa um arquivo SQL informado. |
| `npm run mvc:check` | Verifica limites básicos entre camadas MVC. |
| `npm test` | Executa testes Node em `test/*.test.js`, se existirem. |

### `gov.br-fake`

| Script | Função |
| --- | --- |
| `npm start` | Inicia o simulador local. |
| `npm run check` | Valida a sintaxe de `server.js`. |
| `npm test` | Executa testes Node em `test/*.test.js`, se existirem. |

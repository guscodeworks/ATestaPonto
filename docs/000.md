# ATestaPonto - Introdução

O ATestaPonto é um sistema web de controle de ponto escolar criado para substituir o registro manual em caderno por um processo digital, rastreável e mais seguro.

O projeto atende dois grupos principais:

| Público | Papel no sistema |
| --- | --- |
| Funcionário | Acessa a tela de ponto, faz login e registra as batidas do dia. |
| Administrador | Acessa o painel administrativo, gerencia funcionários, consulta pontos e acompanha relatórios. |

## Contexto

Antes do ATestaPonto, o controle de presença era feito em caderno físico. Esse processo dependia de assinatura manual, conferência posterior e organização em papel. Na prática, isso dificultava consultas antigas, permitia esquecimentos, atrasos de preenchimento, rasuras e registros difíceis de auditar.

A proposta do projeto é aplicar uma solução web a um problema real do ambiente escolar: registrar a jornada dos funcionários com autenticação, validação de localização, armazenamento em banco de dados e acompanhamento administrativo.

## Organização do repositório

O repositório possui dois projetos separados:

| Pasta | Finalidade |
| --- | --- |
| `ponto-escolar` | Sistema principal. Contém telas, APIs, banco de dados, regras de negócio, autorização administrativa e registro de ponto. |
| `gov.br-fake` | Simulador técnico local do Gov.br/Login Único. É usado apenas para desenvolvimento e demonstração. |

Essa separação é uma decisão importante do projeto. O simulador existe para demonstrar o fluxo de identidade, mas a regra de permissão administrativa pertence ao sistema principal.

> Gov.br autentica a identidade. ATestaPonto autoriza o acesso.

Um token válido do Gov.br, ou do simulador local, confirma quem é o usuário. Ele não libera o painel administrativo sozinho. O `ponto-escolar` sempre verifica internamente se a identidade autenticada está autorizada como administradora.

# Regras de negócio

Este documento descreve as regras que orientam o comportamento do sistema. Os detalhes operacionais de tela ficam no [manual](./MANUAL.md).

## Regra central

> Gov.br autentica. ATestaPonto autoriza.

O provedor de identidade confirma quem é o usuário. O ATestaPonto decide se esse usuário pode acessar a área administrativa.

## Funcionários

| Regra | Motivo |
| --- | --- |
| Funcionário precisa estar cadastrado | O ponto só pode ser associado a uma pessoa conhecida pelo sistema. |
| CPF e e-mail devem ser únicos | Evita duplicidade de identidade e conflito de login. |
| Funcionário inativo não registra ponto | Permite bloquear o uso sem apagar histórico. |
| Senha é armazenada como hash | Evita guardar senha em texto puro. |
| CPF é mascarado em respostas | Reduz exposição de dado pessoal. |

## Cargos e horários

No cadastro atual, cada funcionário recebe um cargo e um conjunto de horários:

1. `entrada`;
2. `saida_almoco`;
3. `retorno_almoco`;
4. `saida`.

Os horários precisam estar em ordem crescente. Isso evita cadastrar uma jornada incoerente, como retorno do almoço antes da saída para almoço.

## Registro de ponto

Cada funcionário pode registrar até quatro batidas por dia:

| Sequência | Tipo |
| --- | --- |
| 1 | `ENTRADA` |
| 2 | `SAIDA_ALMOCO` |
| 3 | `VOLTA_ALMOCO` |
| 4 | `SAIDA` |

Depois da quarta batida, uma nova tentativa no mesmo dia deve retornar conflito.

## Localização

Antes de gravar o ponto, o sistema valida latitude e longitude enviadas pela interface. A distância é calculada em relação às coordenadas da escola configuradas no `.env`.

Se o funcionário estiver fora do raio permitido, o registro é bloqueado.

## QR Code

O QR Code atual representa um atalho fixo para:

```text
/ponto/acessar
```

Ele não contém token, senha, permissão nem identidade. O funcionário ainda precisa fazer login e passar pela validação de localização.

## Administração

O administrador pode:

- consultar sessão administrativa;
- listar funcionários;
- cadastrar funcionário;
- consultar um funcionário;
- editar dados administrativos do funcionário;
- desativar e reativar funcionário;
- listar cargos;
- consultar pontos do dia;
- gerar relatório diário;
- consultar resumo do dashboard;
- gerar, listar e validar o atalho de QR Code.

## Relatórios

Os relatórios usam a data no fuso `America/Sao_Paulo`. Isso é importante porque o dia de ponto precisa acompanhar o horário local da escola, não necessariamente o fuso do servidor.
